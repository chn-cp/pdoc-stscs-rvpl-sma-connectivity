# Statistical validation specification

The validation plan was locked before the additional analyses on 23 October 2026.
Previously generated source files and results were treated as read-only inputs. Unit of inference is the patient. Target is six-month MCS+/EMCS attainment among stSCS-treated patients, not causal treatment benefit.

1. Reproduce all 435 Welch tests, focused/strict Firth estimates and anatomical-family model estimates against frozen inputs before prose editing.
2. Uniform residual permutation: 5,000 iterations for main/strict primary, all candidate-family members and displayed main/strict robustness specifications. Shared identical specifications are computed once. Preserve the original coefficient statistic, OLS feature residualisation, nuisance covariates, Firth penalty and plus-one two-sided rule. Retain the old estimates as historical, not selectively replace a Monte Carlo run. Report binomial Monte Carlo uncertainty and convergence diagnostics.
3. Calibration: 2,000 nuisance-only null outcomes per tested design, 5,000 residual permutations each. Keep actual covariates/features/missingness and condition simulated Bernoulli outcomes on the observed event count. First assess main primary, strict primary and R_mRt-SMA as a nonfocused seed; document this limited design coverage. Compare permutation and Wald null rejection rates at .05/.01 with binomial intervals and reference QQ/ECDF. No selection step is simulated: calibration does not provide post-selection validation. Numerical C++ acceleration is permissible only after agreement checks with archived Python fits; no statistical method substitution.
4. Compute within-family BH for both uniform permutation and Wald P. Inferential emphasis follows calibration, not which method yields a smaller P.
5. Complete-case sensitivity: require all 435 finite entries in the original 30-node matrices. Same Welch tests; report n/outcomes/rank/top ten. Do not replace the edge-wise original screen.
6. Max-|Welch t| FWER sensitivity: 10,000 common patient-level outcome-label permutations, retaining each edge's missingness. Report exchangeability assumption and any group-size-degenerate permutations; never use effective-test-count adjustments.
7. Global-FC sensitivities: raw mean Fisher-z of available nonfocused edges and mean R_VPL-to-cortex excluding SMA, separately adjusted alongside the original clinical covariates. Report availability, attenuation and Wald intervals. Add edge-count adjustment only if its association with global FC or outcome is clear (descriptive |rho| >= .4 or two-sided P < .05); report all tested specifications, not just positive ones.
8. Spatial cohort audit: trace original scan/covariate/seed availability and >=90 retained-frame rule. Keep 6mp counts distinct from the fixed 114-voxel predictor overlap. Influence diagnostics, if feasible, are QC, not new spatial significance tests.
9. Table 1/attrition: existing deidentified sex and clinical records only, no inferred gender/race and no underpowered sex interaction. Concurrent interventions are assessed only from reliable retained fields, with missing evidence disclosed.
10. New results enter a canonical CSV, supplement and Source Data before manuscript/cover editing. Manuscript focus remains R_VPL-SMA, truthful contribution first. Public release contains code only; restricted patient-level inputs are not distributed.
